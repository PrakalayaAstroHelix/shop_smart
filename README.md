# ShopSmart 🛍️

**ShopSmart** is a product discovery and price comparison website designed to help users explore products across different categories and compare prices and offers from multiple shopping platforms in one place.

## ✨ Features

- **Product Search:** Search for products by name.
- **Category Filtering:** Browse Beauty, Electronics, Fashion, Groceries, Food, Books, and Toys.
- **Price Comparison:** Compare product prices and offers across different platforms.
- **Trending Products:** Explore featured trending products.
- **Wishlist:** Save your favorite products for later.
- **Shopping Cart:** Add products, view cart items, remove products, and change platforms.
- **Recently Viewed:** Keep track of recently viewed products.
- **Search History:** Store recent search terms.
- **Dark Mode:** Switch between light and dark themes.
- **User Profile:** Enter a username to personalize the experience.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser, or use the Live Server extension in Visual Studio Code if available.
4. Explore the products and try the available features.

No backend server or database setup is required for the current demo.

## 📁 Project Structure

The project contains the website's HTML page, CSS styling, JavaScript functionality, and product data files.

- `index.html` — Main website structure
- `style.css` — Styling and visual layout
- `script.js` — Search, filtering, wishlist, cart, and other interactive features
- `data/` — Product data and related category files, if included in the repository

## 💾 Data Storage

ShopSmart uses the browser's Local Storage to retain information such as wishlist items, cart contents, recently viewed products, search history, theme preference, and username on the same browser.

## ⚠️ Project Notes

ShopSmart is a front-end demonstration project. Product information and prices depend on the data included in the project. Live price synchronization, real payment processing, and actual shopping-platform checkout integrations are not implemented in the provided functionality.

## 🎯 Project Objective

The objective of ShopSmart is to make product discovery and price comparison simpler by presenting product information, available offers, and interactive shopping features through a single interface.
